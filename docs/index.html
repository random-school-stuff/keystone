The web,
unlocked.

Search the web or paste any address. Keystone opens it inside a sandboxed session, so you can reach it from anywhere. 



				

					
					
					
					
					
					
				


				

					

						

							
						

						
Encrypted in transit

						

							Your browser talks to the proxy over an encrypted Epoxy tunnel, so
							the connection stays private end to end.
						

					


					

						

							
						

						
Sandboxed session

						

							Every site runs inside an isolated service-worker scope, separate
							from your normal browsing context.
						

					


					

						

							
						

						
Nothing to install

						

							The whole page is plain static HTML. The only moving part is the
							proxy endpoint you point it at.
